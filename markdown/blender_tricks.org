* blender tricks

Here is a collection of blender tricks I always forget about

*** render options

- Sampling :: noise and sample number
- Light paths :: from 12 to 4
  - illumination :: limited
  - fastGI :: fast global illumination approximation
  - light tree :: for multiple sources
- Simplify :: texture limit to set
  - camera culling :: only the objects in view are rendered
- bake :: the texture once (for procedural texture)
- memory :: lower tile size
- persistent data :: turned on
- layer :: separate collections into layers
- output :: exr image (faster than png)
