# SQL

SQL is an industry standard and its long life allows companies to invest in data pipelines which will last long. Additional work needs to be done to handle the different dialects but most of the modern data warehouses interpret SQL to allow backward compatibility. 
I've been using SQL at the beginning to interface with databases in web applications and then moved to interact with ERP systems. In the corporate world it was used to run big queries to extract data from large datalakes.
