This document provides comprehensive specifications for all IoT controller devices supported by the Blender Twin IoT Controller system. Each device serves specific roles within the IoT sensor controller architecture.

* Device Overview

We have the following devices available:

- [[id:m5stack][M5Stack Core 2 - ESP32 Development Platform]] :: mainly as BLE midi controller and voice assistant
- [[id:esp32_CAM][ESP32-CAM - Vision Sensor Controller]] :: as remote camera serving a web-page
- [[id:arduino_mkr1000][Arduino MKR1000 - WiFi IoT Controller]] :: to send sensor data
- [[id:Arduino_R4][Arduino R4 - IoT Sensor Controller]] :: as DSP using 
- [[id:raspberry_pi_pico-intro][raspberry]] :: as DSP 
- [[id:teensy][Teensy 3.6 - High-Speed Microcontroller]] :: as audio processing

** Device Categories
- Gateway: Multi-protocol (MQTT/HTTP/WebSocket/MQTT-SN)
- Vision: Camera capture and edge vision processing
- Edge Control: Local logic and control nodes
- Gateway/Aggregator: Serial bridge and sensor aggregation

* Installation Prerequisites
:PROPERTIES:
:CUSTOM_ID: installation
:END:

#+NAME: install-checklist
- Flash compatible firmware via Arduino IDE/PlatformIO
- Configure WiFi/Bluetooth credentials
- Set MQTT broker credentials
- Install device drivers
- Upload controller code
- Test sensor connectivity
- Deploy to production network
- Verify device registration
