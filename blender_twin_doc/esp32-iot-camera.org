** Role in IoT Controller
The ESP32-Cam serves as a **vision sensor collector**:

| Role                       | Description                           |
|----------              |-----|
| Camera Sensor Hub         | Captures frames from OV2640 camera     |
| Edge Vision Processing    | Performs basic image analysis          |
| Motion Detection          | Detects movement in captured frames    |
| Image Transmission        | Sends frames via WiFi to controller    |
| Local Storage             | Saves images/snapshots to SD card      |

```cpp
#include <WiFi.h>
#include <Arduino_ESP32Camera.h>
#include "mqtt.h"

String camera_topic = "visionsensor/camera_feed";

void setup() {
  Serial.begin(115200);
  
  WiFi.begin("SENSOR_NETWORK", "sensor_pass");
  
  initialize_camera();
  
  OV2640.begin();
  OV2640.setResolution(RES_VGA);
  OV2640.startCapture([&](const uint8_t* frame, size_t length) {
    mqtt_publish(camera_topic, frame, length);
    check_motion(frame, length);
  });
}

void loop() {
  // Continuous frame capture
  camera_capture();
  
  delay(50);
}
```

  // Open hardware lines
  pinMode(CAMERA_VSYNC, INPUT);
  pinMode(CAMERA_PCLK, INPUT);
  pinMode(CAMERA_XCLK, INPUT);
  pinMode(CAMERA_YEN, INPUT);
  pinMode(CAMERA_PWDN, OUTPUT);
  
  // Initialize camera
  OV2640.begin();
