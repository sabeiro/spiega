* Introduction
:PROPERTIES:
:CUSTOM_ID: introduction
:END:

The Arduino MKR1000 is an all-in-one WiFi IoT development platform designed for quick deployment and connectivity. It features the STM32WL microcontroller, WiFi capability, and an ATmega32U4 for USB interface.

* Code Examples
:PROPERTIES:
:CUSTOM_ID: code-examples

#+NAME: wifi-gateway-example
```cpp
#include <WiFi.h>
#include <WiFiClient.h>
#include <HTTPClient.h>

void setup() {
  Serial.begin(115200);
  Serial.println("WiFi Gateway Starting...");
  
  WiFi.begin("your_ssid", "your_password");
  
  // Wait for connection
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
  }
  
  Serial.println("WiFi Gateway Connected!");
  Serial.print("IP: ");
  Serial.println(WiFi.localIP());
}

void loop() {
  // Forward serial data to MQTT
  if (Serial.available()) {
    String sensor_data = Serial.readStringUntil('\n');
    mqtt_publish("/gateway/collect", sensor_data);
  }
  
  // Process incoming data
  process_sensor_data();
  
  delay(100);
}
```
