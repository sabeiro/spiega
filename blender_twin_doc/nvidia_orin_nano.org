* jetson oring nano

The NVIDIA Jetson Orin Nano is a compact, powerful AI edge computer that provides the computational power necessary for generative AI in small edge devices. This document describes the specifications and integration possibilities within the Blender Twin platform.

* hardware Specifications

** jetson CPU Architecture
:PROPERTIES:
:ID: jetson_cpu-architecture
:END:

- Arm v9 64-bit multi-core CPU
- Up to 4x A78AE cores @ 2 GHz
- Optimized for low latency and high throughput
- Supports Linux-based development environment
- NEON SIMD extensions for AI/ML acceleration

** jetson GPU Architecture
:PROPERTIES:
:ID: jetson_gpu-architecture
:END:

- [[file:https://en.wikipedia.org/wiki/Ampere_(microarchitecture)][NVIDIA Ampere]] architecture
- [[file:https://en.wikipedia.org/wiki/HBM2#High-bandwidth_memory][HBM2e]] with up to 8 GB (two memory options available)
- 1,024 CUDA Cores for parallel processing
- NVENC/NVDEC for hardware video encoding/decoding
- 32 Tensor Cores for AI acceleration
- CUDA 11.x support
- TensorRT for optimized inference
- Supports FP16, INT8 precision
