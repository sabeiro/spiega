* Overview: The Universal IoT Bridge
#+NAME: esp32-overview
The ESP32-WROOM-32 serves as the **universal bridge** connecting all specialized IoT sensor platforms to the Blender Twin ecosystem.

** Platform Mapping
| Target Platform       | Bridge Type        | GPIO Mapping       | Purpose                      |
|--------------------|--------------|---------|----------|
| **Xiao ESP32S3**   | Single-node bridge   | Direct GPIO passthrough   | Compact sensor nodes       |
| **daisy_seed**     | Multi-node bridge    | I2S/PWM passthrough       | Audio/multisensor hubs     |
| **axoloti/akso**   | Audio bridge         | I2S audio routing         | Audio systems              |

** Common Features
- WiFi 802.11 b/g/n/ac + Classic BT
- BLE 5.2 for mesh networking
- 32 GPIO pins (platform-specific variations)
- ADC/DAC interfaces
- Dual-core Xtensa LX7 240MHz
- 8-16MB RAM, 8-16MB Flash

** I2C Multi-Platform Sensor Fusion
#+BEGIN_SRC cpp
// Bridge universal sensor readings across platforms
#include <Wire.h>

void setup() {
  // Initialize multi-platform I2C
  Wire.begin(3, 4);  // SDA, SCL
  
  // I2C scan
  Wire.setClock(100000);
  
  // Start BME280 (daisy_seed, axoloti)
  bme280_i2c.begin(0x76);
  
  // Start MPU6050 (all platforms)
  mpu6050_i2c.begin(0x68);
}

void loop() {
  // Read universal sensor data
  float temperature = bme280_i2c.readTemperature();
  float pressure = bme280_i2c.readPressure();
  
  // Bridge to Xiao or axoloti
  ble_publish("sensor/temperature", String(temperature));
  
  delay(1000);
}

* Bridge Architecture Summary
#+NAME: esp32-bridge-architecture
** The ESP32-WROOM-32 serves as the universal bridge connecting specialized platforms:**

1. **daisy_seed** → **ESP32-WROOM-32** → **axoloti/akso**
   - daisy provides sensor nodes and I2S audio
   - ESP32-WROOM bridges I2C/PWM data to axoloti DSP
   - axoloti handles real-time audio processing

2. **xiao** → **ESP32-WROOM-32** → **BLE Mesh Network**
   - Xiao provides compact sensor nodes
   - ESP32 handles WiFi gateway functions
   - BLE mesh for device discovery

3. **axoloti** → **ESP32-WROOM-32** → **WiFi Cloud**
   - axoloti provides audio processing
   - ESP32 provides WiFi MQTT publishing
   - Cloud MQTT subscription

** Cross-Platform Data Flow**
```
[ daisy_seed ] <--I2C/PWM---> [ ESP32-WROOM ] <--I2S/PWM---> [ axoloti ]
                              |
                              +--BLE Mesh---> [ xiao ]
                              |
                              +--WiFi MQTT--> Cloud
```
