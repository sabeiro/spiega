** Optimization Strategy (Single-GPU System)
- Use int4 quantization (q4_0, q4_K_M) for 8B+ models to fit in 8GB
- Keep smaller models (1B-3B) in full FP16 for fastest inference (~45 tokens/sec)
- Enable RAM fallback via OLLAMA_MAX_VRAM in Ollama container
- Monitor VRAM usage to prevent OOM (keep below ~7GB for safety)
- Run background tasks on CPU cores (tokenization, preprocessing)
- Avoid over-subscription on 8GB GPU - one model at a time
- Use iGPU for non-critical rendering or UI tasks

** Performance Targets (RTX 5060, 8GB VRAM)
- Single 8B model: 10-20 tokens/sec (int4)
- Single 3B model: 30-45 tokens/sec (FP16)
- 7B model: 7-15 tokens/sec (int4, quantized)
- 13B model: 4-8 tokens/sec (int4, heavy quantization)
- 170B (LLaMA 3.1 70B): ❌ Needs quantization, ~2-5 tokens/sec
- Multi-model: 5-10 tokens/sec (concurrent requests)
- VLM (vision): 15-25 tokens/sec (int4)
