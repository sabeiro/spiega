* Introduction
:PROPERTIES:
:CUSTOM_ID: introduction
:END:

The Teensy 3.6 is Arduino-compatible microcontroller powered by the NXP Kinetis K66 ARM Cortex-M4F processor, clocked at 96 MHz. It's designed for high-speed applications with excellent GPIO capabilities, analog performance, and low-latency I/O.

* Code Examples

#+NAME: teensy36-basic
```cpp
#include <SPI.h>
#include <EEPROM.h>

const int adcPin = A0;
float sensor_data = 0;

void setup() {
  Serial.begin(115200);
  
  pinMode(adcPin, INPUT);
  
  // Configure SPI
  SPI.begin();
  SPI.setClockDivider(SPI_CLOCK_DIV2);
  
  Serial.println("Teensy 3.6 Booting...");
}

void loop() {
  // Read ADC
  sensor_data = analogRead(adcPin);
  
  // Process data
  if (sensor_data > 1000) {
    Serial.println("High detection!");
  }
  
  // Publish to MQTT
  publish_to_mqtt();
  
  delay(100);
}
```
