** Initialize I2C Sensors
#+BEGIN_SRC cpp
#include <Wire.h>

void setup() {
  Wire.begin(GPIOR_OUT, GPIOR_IN);  // I2C pins
  Wire.setClock(100000);            // 100kHz I2C

  // BME280 pressure/temperature/humidity
  bme.begin(0x76);
  Serial.print("BME280: "); Serial.println(bme.isConnected() ? "connected" : "not found");

  // MPU6050 accelerometer
  Wire.beginTransmission(0x68);
  Wire.write(0x6B);  // Gyro
  Wire.endTransmission();
  Serial.print("MPU6050: "); Serial.println("connected");
}

void loop() {
  // Read sensors
  float pressure = bme.readPressure() / 100.0;
  float temp = bme.readTemperature();
  float accelX = mpureadAccelerometerX();
  Serial.print("P: "); Serial.print(pressure);
  Serial.print(" T: "); Serial.println(temp, 2);
  
  delay(1000);
}

* Project Integration

** Daisy Chain Architecture
#+NAME: daisy-daisy-chain
Multiple daisy seed boards can be chained together:
- Use BLE 192-bit mesh network
- Each board acts as network node
- Central hub coordinates all devices
- Total nodes: 100+ (BLE mesh limitation)

** Sensor Fusion
| Node Type    | Use Case                              |
|-------------------|----------------------------|
| **Sensor Node**  | Environment monitoring             |
| **Actuator Node**| Relay/Valve control                |
| **Gateway Node** | Bridge to MQTT/WiFi cloud          |
| **Router Node**  | BLE mesh routing                   |
