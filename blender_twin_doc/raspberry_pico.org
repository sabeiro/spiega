* Introduction
:PROPERTIES:
:ID: raspberry_pi_pico-intro
:ROAM_ALIASES: raspberry pi pico intro
:END:

The Raspberry Pi Pico is a compact, low-cost microcontroller built around the RP2040 chip by Raspberry Pi Foundation. It features a dual-core ARM Cortex-M0+ processor, 264 KB SRAM, and extensive I/O capabilities. It's popular for hobbyist projects, educational use, and IoT applications.

* Code Examples
:PROPERTIES:
:CUSTOM_ID: code-examples
:END:

#+NAME: pico-basic-example
```micropython
from machine import Pin, ADC
import time

adc = ADC(Pin(26))
pin_led = Pin(25, Pin.OUT)

def setup():
    adc.width(12)
    pin_led.value(0)

def read_sensor():
    return adc.read_u16()

def loop():
    sensor_data = read_sensor()
    pin_led.value(sensor_data > 2000)
    time.sleep(1)

setup()
loop()
```
