** I2C Sensor Read Example
#+BEGIN_SRC cpp
#include "BME280_Arduino.h"

void setup() {
  Serial.begin(115200);
  bme.begin(0x76); // Default I2C address
}

void loop() {
  float T = bme.readTemperature();
  float P = bme.readPressure();
  float H = bme.readHumidity();
  Serial.print("T: "); Serial.println(T, 2);
  Serial.print("P: "); Serial.println(P, 2);
  Serial.print("H: "); Serial.println(H, 2);
  delay(1000);
}
```

* Project Integration

- MQTT broker communication for cloud integration
- OTA firmware updates via serial

* GPIO Limitations Note
:PROPERTIES:
:ID: xiao-gpio-limitations
:END:

#+NAME: gpio-limitations
- Total available GPIO pins: 20
- Only 15 are user-programmable (some reserved)
- PWM resolution: 8-bit maximum
- ADC accuracy: ~3% at room temperature
- No native audio DAC
- Limited interrupt pins (GPIO 23+ reserved)

* Flash Storage Note
:PROPERTIES:
:CUSTOM_ID: flash-storage-esp32
:END:

This board shares 8MB flash between:
- System bootloader (~400KB)
- User application (~6-7MB)
- OTA update space
