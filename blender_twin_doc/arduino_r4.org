* Introduction
:PROPERTIES:
:CUSTOM_ID: introduction
:END:

The Arduino R4 WiFi (also known as Arduino Nano R4 WiFi) is a sophisticated IoT controller designed for embedded AI and sensing applications. It represents a significant upgrade from traditional Arduino boards, combining the ATmega32U4 microcontroller with WiFi capabilities.

* Hardware Specifications
:PROPERTIES:
:CUSTOM_ID: hardware-specifications
:END:

** Core Processor
:PROPERTIES:
:CUSTOM_ID: core-processor
:END:

- ATmega32U4 32-bit microcontroller
- 16 MHz clock speed
- 32 KB Flash memory
- 2.5 KB SRAM
- 1 KB EEPROM
- 18 digital IO pins (2 PWM outputs)
- 6 analog inputs

** WiFi Communication
:PROPERTIES:
:CUSTOM_ID: wifi-communication
:END:

- WiFi Direct connectivity
- 802.11b/g/n standard
- 2.4 GHz WiFi range
- Built-in WiFi module
- Point-to-point and point-to-multipoint
- Direct client-to-client communication

```cpp
const char* ssid = "your_network";
const char* password = "your_password";

void setup() {
  Serial.begin(9600);
  delay(1000);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.println("Connecting to WiFi...");
  }
  
  // Setup sensor readings
  sensor_data_init();
}

void loop() {
  // Read sensors
  double temp = read_temperature();
  double hum = read_humidity();
  
  // Create payload
  JsonVariant payload = create_json_payload(temp, hum);
  
  // Publish
  MQTT.publish("sensors/arduino-r4", payload);
  
  delay(1000);
}
```
